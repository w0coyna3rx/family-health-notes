# 我们公开又隐秘的性生活

> 更新时间：2026-09-16 (UTC+8)

1.谜题

小时候家里只有一面镜子，镶在爸妈房间的老式衣柜上。

每天早上上学前，我都去那里梳头。

有一次，撞到紧急停下动作、假装睡觉的爸妈。

照理来说，解决这个问题很简单，再买一面镜子放在外面就可以。但始终没有。有时我在想，是不是因为一旦买了镜子，那次的假装就坐实了。

为了证明那天我什么也没发现，我依然坚持每天去梳头。

有时我在想，在中国，“无性之家”是“荣誉之家”。

有时我又想，也许这里头有一种谁也不捅破的刺激。

2. 极简主义

一个极具人文关怀的说法：

自慰是一种独立、极简的性行为。

偶尔想抢下全国所有校园广播室的喇叭，有感情地朗读这句话。

3. 不是什么高级的，也不是什么低级的

北京的文明体现在墙上没什么脏话。

每次回到小城市的家，能看见很多墙上的“器官文学”，多数是幼稚的笔体。

小时候不知道性为何物的时候，常常在墙上写出露骨的话。

真正知道性是什么的时候，反倒羞于启齿了。

很难讲，矫枉过正算不算一种进步。

4. 拥抱

凌晨收到的微信中，有和老板吵架的女性朋友，有失恋的女性朋友，有性行为后索要拥抱未果的女性朋友。

从凌晨收到微信的性别比例来说，男性朋友的睡眠质量要比女性朋友高。

女性朋友说：爱对男的来讲，在性开始的时候。对女的来讲，也许恰巧在性结束的时候。

在微信的另一端，屏幕照亮脸庞的女哲学家和她早已酣睡的男朋友。

女：一个拥抱而已（他都不肯给我）。

男：一个拥抱而已（没必要这么在乎……吧）。

5.高估性高潮

此刻一：花坛边，斜坐一对男女，男人帮女人拔倒刺，男人手上茧太厚，拇指和食指捏住倒刺的角度太大，定，拔！倒刺纹丝不动，男人的手指头已经掐到轻微发白，血液不通了。女人轻微翘起的身体表皮和心思一样难以捕捉！但男人不泄气。到底是因为一直拔不到倒刺才握着手，还是因为想一直握着手才拔不到倒刺呢？

此刻二：春天，正午，太阳下，一对并行的爹爹和婆婆，各自随身带一把瘦长的折叠椅，想坐下的时候就坐下，想走路的时候就把椅子合起来当拐杖。人到暮年，一起散步的难度，更像是一起徒步。但他们要一起走。

很多悲壮又浪漫的生活场景发生时，我会想起《四重奏》里的一句台词：

“这么冷的早晨，在阳台上吃札幌一番拉面真是美味啊。把此刻当成你我二人的高潮，不好吗？”

人类对性高潮的重视程度太高了。把“此刻”当成性高潮，世界将变成性高潮的人间。

6.送你一片杜蕾斯

在广告行业的时候，有一整年，我的桌上都放着各式各样的避孕套。我们这一片有一个标志性景观——一根套着层层叠叠避孕套的筷子。

我们服务的客户是杜蕾斯。

“这次选题会我主要提出一个问题，为什么这么久了，我们性生活还是会痛，我是指我，我会痛！”

“今天我打算做一下关于冠状沟的研究。”

“我准备做一个色卡，向大家解释一下‘黑木耳’的说法为什么不尊重人。”

同事们偶尔互赠样式可爱的避孕套，对彼此的性生活说“加油”。

很难分辨，这是世外桃源还是法外之地。

有时我也想，杜蕾斯的文案之所以能火，大概因为我们在每一个孤独或不孤独的深夜里都面临着无数与性有关的困惑和问题。而每当日光降临，它们都被藏回了心底，没人提起，没人开口。于是人们等待着一个玩笑的出现，在讳莫如深的笑容里暗自点头——是的，那就是我。那是我公开又隐秘的性生活。
