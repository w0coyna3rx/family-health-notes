# 解密试管婴儿（上）

> 更新时间：2026-09-16 (UTC+8)

什么是试管婴儿？

**体外授精-胚胎移植俗称“试管婴儿”**，是指通过超促排卵药物使不孕女性的卵巢同时有多个卵泡发育并成熟，在适当的时机，绝大部分通过经阴道穿刺取卵，在实验室将取出的卵子与男方的精子进行受精，体外培养成胚胎（D3或者D5、D6）再择优移植到女方子宫内继续孕育的过程。此时若有剩余的可移植胚胎通过玻璃化冷冻保存以备后用，移植术后一般需要用8-10周安胎药物，不可随意停药。

在胚胎移植2周检测血HCG（开奖），确认是否妊娠，最终目标是实现健康怀孕。试管婴儿助孕遵循个性化原则，针对不同夫妇采取合适的促排卵方案、受精方式、胚胎移植方案以及移植术后安胎用药。

什么是一代、二代、三代试管婴儿？

**第一代试管（IVF）**，是指把取得的精子和卵子放在一起，通过自然选择，其中最有活力最有竞争力的精子进入卵子内而达到受精的目的，进而发育成胚胎的方式。

**第二代试管（卵胞浆内单精子显微注射，ICSI）**：借助显微操作技术将单个精子直接注射到成熟的卵细胞内以完成受精的过程。主要针对重度少弱精等以及需要睾丸取精的男性不孕症患者的治疗。如果常规受精失败，也可借助该方法。

**第三代试管（胚胎植入前遗传学检测，PGT）：**跟第一代和第二代技术不同之处是胚胎放入子宫之前，取胚胎的少量遗传物质进行检测分析，来判断胚胎是否有异常，筛选出健康的胚胎进行移植。**这种技术在一代程度上降低了有遗传缺陷宝宝的出生率。******

**敲黑板：**如果说第一代”试管婴儿“是自由恋爱，第二代是包办婚姻，那么第三代就是比武招亲，择优录取！

什么情况下需要试管婴儿？

（1）通俗地讲，精卵相遇的通道异常-输卵管不通可做试管。比如炎症导致输卵管堵塞或者通而不畅、输卵管结扎术后、异位妊娠手术切除输卵管后、宫腹腔镜输卵管整形术后6-12月未孕等；

（2）女性卵子异常：比如多囊卵巢综合症、反复促排卵药物治疗失败、多次人工授精未成功、未破裂卵泡黄素化综合征以及卵巢储备功能减退等；（3）妊娠环境异常：子宫内膜异位症，常导致盆腔粘连、输卵管不畅、子宫内膜对胚胎容受性下降及明显免疫反应、影响妊娠各个环节。（4）男方精子异常：精子太少、太弱、或者畸形精子高，不能满足自怀或者行人工授精所需要的数量，比如重度的少精子症、重度的弱精子症、重度的弱精子症等。还有一种就是，男方精液中无精子检出，但是睾丸或者附睾穿刺可以找到精子，也可以通过试管婴儿助孕。（5）不明原因不孕：经过多个周期（≥3个周期）的人工授精失败后可以选择试管婴儿。但是我们建议，如果是原发不孕，且找不到明确的不孕原因，最好先排除下免疫凝血方面的因素，再进行试管婴儿助孕。（6）遗传方面异常：如果男女一方或者双方存在染色体或者基因水平的遗传性疾病，可考虑通过第三代试管婴儿筛选出正常胚胎进行移植后怀孕。

试管婴儿的费用大概多少？

**常规第一代和第二代试管婴儿的费用大概在3至4万之间，第三代试管婴儿因需要做遗传学检测会更昂贵一些。**此外，也与不同生殖中心、自身合并疾病以及做试管婴儿过程中可能发生的合并症等也有关系。

做试管婴儿前男女双方需要做什么准备？

**除了完善医学上必须做的检查项目外，夫妻双方最好提前三个月做身体方面的准备：**

1. 调整心态，避免不良的心理因素；

2. 适当锻炼身体，比如快走、跑步、游泳等，保持合适的体重；但是切记促排卵过程中及取卵后3个月内翻身、转身时需要放慢速度，避免剧烈运动，以免发生卵巢扭转。

3. 养成规律的作息习惯，避免熬夜；

4. 合理的饮食，少进食烧烤、外卖、油炸食品，少饮富含咖啡因的饮料，戒烟酒，戒浓茶等；

5. 合理补充叶酸和维生素D等。
